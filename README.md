# 🎙️ AI Lecture Voice Notes

### *Speak it. Capture it. Learn it.*

Turn lectures, spoken explanations, and ideas into organized notes with AI-powered voice-to-text functionality.

[Live Demo](https://ai-lecture-voice-notes-qbxkzior8.vercel.app/) | [GitHub Repository](https://github.com/SAHILMISHRA-9/AI-lecture-voice-notes)

---

## 📚 What is AI Lecture Voice Notes?

Ever struggled to keep up with a fast-paced lecture while trying to write everything down? AI Lecture Voice Notes makes note-taking easier.

Speak naturally, capture your speech as text, and organize your thoughts into structured notes — all directly from your browser.

Whether you're attending a lecture, brainstorming an idea, or recording important explanations, this application helps you focus on understanding rather than constantly typing.

No manual transcription required. Just speak, capture, and organize.

## ✨ Features

- 🎤 **Voice-to-Text Transcription** — Convert spoken words into text using browser-based speech recognition.
- 📝 **Real-Time Speech Recognition** — Capture spoken content directly into your notes.
- 🧠 **Flashcard Generation** — Turn your notes into flashcards to support learning and revision.
- ✏️ **Editable Notes** — Modify and refine your captured notes whenever needed.
- 🌐 **Browser-Based Experience** — Use speech recognition directly through supported browsers.
- 📱 **Responsive UI** — Designed to provide a smooth experience across different screen sizes.

## 🕹️ How It Works

1. Open AI Lecture Voice Notes in your browser.
2. Start speaking using the voice recording functionality.
3. The application captures your speech and converts it into text.
4. Review, edit, and organize your transcribed notes.
5. Use timestamps to keep track of your lecture content.
6. Generate flashcards from your notes for easier revision.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/SAHILMISHRA-9/AI-lecture-voice-notes.git

cd AI-lecture-voice-notes
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

> Note: Speech recognition functionality depends on browser support and microphone permissions.
